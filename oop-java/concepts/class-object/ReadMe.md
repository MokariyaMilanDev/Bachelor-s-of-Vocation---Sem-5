# Class & Object

## Class

**Class:** A _class_ is a user-defined `blueprint` or `template` used to create **objects**

##### Syntax

```java
class <ClasName> {
   // Body
}
```

## Object

**Object:** An _object_ is an `instance` of a **class**

##### Syntax

```java
<ClassName> <ObjectName> = new <ClassName>();
```
