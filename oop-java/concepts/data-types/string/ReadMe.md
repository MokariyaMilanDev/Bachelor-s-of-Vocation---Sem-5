# String

> Array of characters

##### Syntax

```java
String <Name> = "...";
```

#### Methods

##### `.length()`

```java
<Name>.length()
```

##### `.concat()`

```java
<Name>.concat(<String> string)
```

##### `.equals()`

```java
<Name>.equals(<String> string)
```

##### `.compareTo()`

```java
<Name>.compareTo(<String> string)
```

##### `.compareToIgnoreCase()`

```java
<Name>.compareToIgnoreCase(<String> string)
```

##### `.indexOf()`

```java
<Name>.indexOf(<String> string)
```

##### `.charAt()`

```java
<Name>.charAt(<int> index)
```

##### `.substring()`

```java
<Name>.substring(<int> beginIndex)
```

##### `.toUpperCase()`

```java
<Name>.toUpperCase()
```

##### `.toLowerCase()`

```java
<Name>.toLowerCase()
```
