# Array

##### syntax

```java
<DataType> <Name>[] = { <Element>, <Element> };
```

# ArrayList

```java
ArrayList<<DataType>> <Name> = new ArrayList<>();
```

#### Methods

##### `.add()`

```java
<Name>.add(<Element>)
```

##### `.get()`

```java
<Name>.get(int <Index>)
```

##### `.set()`

```java
<Name>.set(int <Index>, <Element>)
```

##### `.remove()`

```java
<Name>.remove(int <Index>)
```

##### `.size()`

```java
<Name>.size()
```

##### `.clear()`

```java
<Name>.clear()
```
