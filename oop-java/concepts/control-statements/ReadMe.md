# Control Statements

## if...else

##### Syntax

```java
if(condition){
   // if body
}else{
   // else body
}
```

## switch

##### Syntax

```java
switch(expression){
   case value1:
      // body
      break;
   case value2:
      // body
      break;
   default:
      // body
}
```

## Ternary Operator

##### Syntax

```java
variable = (condition) ? value_if_true : value_if_false;
```
