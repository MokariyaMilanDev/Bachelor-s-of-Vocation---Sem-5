# OOPs - Java

## Basics

- Java developed by `Sun Microsystem`
- Java first called as `Hot Java`
- Java extension `.java`
- Process: **Source Code** (`.java`) -> **Compile** (`.class`) -> **Run**
- Compiler: **JDK** (`Java Development Kit`)
- Runtime: **JRE** (`Java Runtime Environment`)
- Engine: **JVM** (`Java Virtual Machine`)

#### Features

- **Object-Oriented**
- **Platform Independent**
- **Robust and Secure**
