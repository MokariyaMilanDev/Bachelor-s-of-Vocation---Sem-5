> 1. Create **.not** project

```bash
dotnet new <TEMPLATE_SHORT_NAME> -n <PROJECT_NAME>
```

#### Common Project Templates

**App** `dotnet new console`
**ASP.NET Core Web API** `dotnet new webapi`
**ASP.NET Core MVC** `dotnet new mvc`
**Class Library** `dotnet new classlib`
**xUnit Test Project** `dotnet new xunit`

> 2. Run project

```bash
dotnet run <MAIN_FILE>
```
